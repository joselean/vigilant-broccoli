# ULTIMA HOST

Сайт-каталог и Telegram-бот для ресейла VDS на базе Hetzner Cloud. Клиент выбирает тариф в боте, оплачивает — сервер создаётся автоматически через Hetzner API, доступы приходят в Telegram.

## Структура монорепозитория

```
apps/
  web/    — сайт на Next.js (лендинг + каталог тарифов)
  bot/    — Telegram-бот (grammY): каталог, заказ, оплата, выдача сервера
packages/
  db/     — Prisma-схема и клиент БД (Postgres), общая для web и bot
  core/   — бизнес-логика: Hetzner API, платёжные провайдеры, сервис заказов
```

## Как это работает

1. Пользователь открывает бота → видит тарифы → жмёт «Заказать».
2. Создаётся заказ в БД, бот показывает реквизиты/ссылку на оплату.
3. После подтверждения оплаты (админом вручную, либо вебхуком платёжного провайдера) вызывается `confirmOrderPayment`, который создаёт сервер через Hetzner Cloud API и отправляет клиенту IP/пароль.
4. Сайт — витрина тарифов и лендинг; сама покупка проходит через бота.

Пока не подключены реальные ключи Hetzner/платёжной системы, всё работает в **demo-режиме**: сервер «создаётся» с фейковым IP, а оплата подтверждается вручную командой админа в боте — это позволяет протестировать весь сценарий целиком уже сейчас.

## Быстрый старт

Требования: Node.js 20+, pnpm 9+, Docker (для Postgres).

```bash
pnpm install
cp .env.example .env   # заполните BOT_TOKEN и ADMIN_CHAT_ID

docker compose up -d           # поднять Postgres
pnpm db:migrate                # применить миграции
pnpm db:seed                   # засеять тестовые тарифы

pnpm dev:web                   # сайт на http://localhost:3000
pnpm dev:bot                   # бот (long polling)
```

## Настройка переменных окружения (`.env`)

Скопируйте `.env.example` в `.env` и заполните:

- **`BOT_TOKEN`** — токен бота от [@BotFather](https://t.me/BotFather).
- **`ADMIN_CHAT_ID`** — ваш Telegram user id (узнать у [@userinfobot](https://t.me/userinfobot)) или id группы для уведомлений об оплате.
- **`HETZNER_API_TOKEN`** — токен из Hetzner Cloud Console → ваш проект → Security → API Tokens (права Read & Write). Пока пусто — бот работает в demo-режиме.
- **`PAYMENT_PROVIDER`** — `manual` (по умолчанию, оплата вручную/по реквизитам с подтверждением админом), `yookassa` или `cryptobot`, если подключите готовый провайдер (см. `packages/core/src/payments`).

## Тарифы

Тарифы (название, CPU/RAM/диск, цена, соответствующий `server_type` и локация Hetzner) заданы в `packages/db/prisma/seed.ts`. Отредактируйте цены и параметры под свою маржу и перезапустите `pnpm db:seed`.

## Деплой

- **web** и **bot** — независимые Node-процессы, можно развернуть на одном VPS (например, том же Hetzner) через `pm2`/`systemd`/Docker.
- Постоянная БД — Postgres (см. `docker-compose.yml`), для продакшена вынесите её на отдельный managed-инстанс или volume с бэкапами.
- Для веб-хуков платёжных систем используйте `apps/web/app/api/payments/webhook` — эндпоинт-заготовка, перед продакшеном обязательно добавьте проверку подписи запроса конкретного провайдера.
